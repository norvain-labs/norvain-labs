
# NorVain Labs

**Building practical web technologies and digital products.**

NorVain Labs is an independent software initiative based in Türkiye, focused on developing web solutions for businesses and customizable digital products for developers.

Currently built and maintained by a solo developer.

[Website](https://norvainlabs.com) · [Explore Templates](https://github.com/norvain-labs/Norvain-Website-Templates) · [Gumroad](https://norvain.gumroad.com)

## What We're Building

Our work focuses on three areas:

- **Web Development** — Websites and web applications for businesses.
- **Developer Products** — Reusable source-code templates for freelancers, developers, and small agencies.
- **Software Products** — Independent applications and tools currently in development.
